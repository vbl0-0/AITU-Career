Repository and Traceability

  1. Use one GitHub or GitLab repository throughout the diploma project. Each of the two students uses a personal account and identifiable commits.
  2. Give both team members, the supervisor and committee appropriate access. Check actual access before submission.
  3. Create real tracker tasks and assign each to one of the two students. Record the expected outcome, priority, acceptance criteria and deadline.
  4. Use actual task IDs in branches and commit/merge-request descriptions. Link the implementation back to its task.
  5. Keep main as the checked baseline. Preserve actual review comments and disclose AI-assisted checks; do not invent a human review.
  6. Tag the exact reviewed version prob-period-1 without moving previously submitted tags. Do not fabricate earlier history.
  7. Exclude secrets, local databases and identifying research records.
